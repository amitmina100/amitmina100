Put one candidate packet per file: `candidates/<firstname-lastname>.md`.

Structure the file with labelled sections, any of which may be absent:

# LINKEDIN
<raw LinkedIn profile text: headline, About, activity, every role verbatim,
education>

# GITHUB
<repo listing as shown on the profile page; include README text for
personal projects if you have it>

# SCHOLAR
<paper titles, venues, years, authorship position, citation counts>

# RESUME
<raw text>

Rerun answers go in `candidates/<firstname-lastname>-answers.md`, each item
tagged [public_artefact], [self_reported], or [interviewer_observed].
