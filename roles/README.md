Put transformed roles here, one per file, named `role - <Role Name>.md`.

A transformed role has four sections:
1. GROUND TRUTH — what the job really is, its non-negotiables, level, comp
   band, and how far the band can stretch.
2. IS — bullets describing what a match looks like.
3. IS NOT — adjacent roles that share keywords but are not this job, each
   with the keywords they share.
4. DISAMBIGUATION RULE — the one paragraph a matcher uses to separate IS
   from IS NOT.

A raw JD works too; seats will read it directly, but the Chair's ruling is
sharper with the transformed version.
